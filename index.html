📱 手机输入

手机扫码后，手机上打的字会实时填进电脑上的格子（带 📱 的那一格）。可以用手机的输入法、键盘听写来写翻译；手机上能切换栏、上下行、跳到下一个空白格，还能让电脑播放这一句。

第一次使用：先把手机输入页放到网上（只需设置一次）
  1. 手机没法直接打开你电脑里的文件，所以要把和这个工具一起的 phone.html 放到一个网址上。
  2. 方法 A：GitHub Pages（推荐，免费、长期有效）
    在 github.com 新建一个 Public 仓库 → Add file › Upload files 上传 phone.html → 仓库的 Settings › Pages，Branch 选 main 后 Save → 一两分钟后得到 https://用户名.github.io/仓库名/phone.html
  3. 方法 B：Netlify Drop（最快）
    打开 app.netlify.com/drop，把装着 phone.html 的文件夹拖进去，得到一个网址（注册免费账号后才会长期保留）。
  4. 把得到的网址填在下面。之后每次只要扫码就行。
